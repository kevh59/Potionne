# Põtionné - Luxury Fragrance Experience Website

Repositori ini berisi kode sumber untuk website resmi **Põtionné**, sebuah brand parfum mewah dengan estetika eksklusif beraksen *Black & Gold*. Website ini dirancang menggunakan HTML5 dan CSS3 murni tanpa dependensi eksternal yang rumit, sehingga sangat ringan, responsif, dan mudah dipasang di GitHub Pages.

## ✨ Fitur Utama
- **Estetika Premium:** Kombinasi warna Hitam Pekat (`#0a0a0a`) dan Emas Metalik (`#d4af37`).
- **3 Varian Varian Unik:** Citréa (Buah), Floreá (Bunga), dan Royal (Kemewahan Eksklusif).
- **Sistem Keranjang Belanja:** Dilengkapi tombol *Add to Cart* interaktif pada setiap produk.
- **Informasi Lengkap:** Menu Home, Produk/Koleksi, About Us dengan deskripsi naratif, kontak resmi, dan peta lokasi operasional di Kota Bitung, Sulawesi Utara.

## 📁 Struktur Berkas
- `index.html` — Kode utama website (Struktur HTML & Gaya CSS internal).
- `README.md` — Dokumentasi proyek ini.

## 🚀 Cara Menjalankan Proyek
1. *Clone* atau unduh repositori ini ke komputer Anda.
2. Buka file `index.html` langsung menggunakan web browser pilihan Anda (Chrome, Edge, Safari, Firefox).
3. Untuk mempublikasikannya di internet secara gratis, aktifkan fitur **GitHub Pages** melalui pengaturan repositori (*Settings > Pages*).
